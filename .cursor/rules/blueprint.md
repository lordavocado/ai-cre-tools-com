# **App Name**: Sheet2Site Pro

## Core Features:

- Landing Page: Landing page with a hero section, newsletter subscription form, directory overview, categories, and guides sections. Optimized for SEO.
- Detail Pages: Display directory item details fetched from Google Sheets, incorporating SEO-friendly practices. Clean UI with shadcn components
- Category Pages: Display an overview of all available categories with links to individual category detail pages. Uses SEO-optimized static pages for category explanations.
- Guides Page: Present guides/blog posts that are SEO optimized. Allows linking to relevant categories and directory entries
- Comparison Tool: Allow users to compare up to 3 directory items side-by-side, with a comparison table to highlight differences. The AI tool suggests key differences based on data extracted from the Google Sheet

## Style Guidelines:

- Primary color: Soft blue (#64B5F6), offering a sense of trust and reliability, fitting for a professional directory.
- Background color: Very light blue (#F0F8FF), to provide a clean, unobtrusive backdrop that keeps focus on the directory content.
- Accent color: Soft purple (#957DAD), positioned as a harmonious analog to the primary blue, adding a touch of creativity without overwhelming the user.
- Clean and modern typography for readability.
- Simple and consistent icons to represent directory categories.
- Clean, grid-based layout optimized for different screen sizes.
- Subtle animations for page transitions.
