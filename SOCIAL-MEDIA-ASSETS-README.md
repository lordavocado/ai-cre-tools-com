## 🛠️ Technical Implementation

### Site Configuration
The images are automatically referenced in:
- **Next.js Metadata**: `src/app/layout.tsx`
- **Site Config**: `src/config/site.ts`
- **Web Manifest**: `public/site.webmanifest`

### Automated Generation
To regenerate images with the automated script:

```bash
# Install dependencies (if needed)
npm install canvas

# Generate all social media images
npm run generate-social-images
```

### Manual Customization
1. Open `scripts/social-media-templates.html` in your browser
2. Screenshot each template section
3. Edit in your preferred design tool (Canva, Figma, Photoshop)
4. Export with correct dimensions
5. Replace files in `public/` directory
