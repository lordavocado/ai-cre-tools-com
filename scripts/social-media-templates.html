How to Use These Templates

🎨 Design Specifications

Primary Colors: Blue gradient (#3b82f6 to #1e40af)

Text Colors: White text on gradient background

Typography: Clean, modern sans-serif fonts

Style: Professional, tech-focused, AI-themed

  1. Open in Browser: This HTML file displays all templates at their correct aspect ratios
  2. Screenshot: Take screenshots of each template section using your browser's developer tools or a screenshot tool
  3. Edit in Design Tool: Open the screenshots in Canva, Figma, Adobe Photoshop, or similar tools
  4. Customize: Replace placeholder text with your actual content while maintaining the design style
  5. Export: Save each image in PNG format with the correct dimensions
  6. Optimize: Compress images for web (under 1MB recommended)
  7. Test: Use tools like opengraph.xyz or social media debuggers to test your images

Alternative: Automated Generation

Run this command in your terminal to generate images automatically:

npm install canvas
npm run generate-social-images
